# BakaLite

A lightweight, intuitive and open-source alternative [Bakaláři](https://bakalari.cz/) client without the tracking and ads found in the official app.

Many thanks to [Bakaláři API](https://github.com/bakalari-api/bakalari-api-v3) project for great documentation.
